# OP Items Mod

Adds powerful OP Items to your Minecraft world

## Features

- Adds OP Swords, Pickaxes, Axes, Shovels, and Hoes
- Adds OP Armor including Helmets, Chestplates, Leggings, and Boots

## Requirements

- Minecraft 1.21.4
- Fabric Loader 0.14.0 or later
- Fabric API

## Installation

1. Download the mod JAR file from the releases page.
2. Place the JAR file in your `mods` folder.
3. Launch Minecraft with the Fabric profile.

## Usage

Once installed, you can find the OP Items in your inventory or crafting menu. These items are designed to be overpowered and provide a significant advantage in gameplay.

## Configuration

This mod does not have any configuration options. All items are added by default.
